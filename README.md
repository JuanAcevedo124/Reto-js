# Tareas asincrónicas en JavaScript

Ejercicio que simula la ejecución de tareas con `setTimeout` y callbacks. Cada tarea tarda según su tipo: simple (1 s), importante (2 s) o crítica (3 s).

## Ejecución

```bash
node index.js
```

También puedes abrir `index.html` y revisar la consola del navegador.
